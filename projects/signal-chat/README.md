# Signal Chat

An Angular messenger by **Sudip Sah** (@sudip09-sys), for Sudip Lab.

## Use
Open the app in the workspace or serve this repository over HTTP. Register two demo accounts in separate tabs for live local messaging. Use demo passwords only. The guide contact is simulated. Remembered accounts, known contacts, and messages remain in this browser.

## Source and build
Editable Angular and TypeScript source is in source/. Run npm install and npm run build there. A ready-to-run production build is included in this folder. Run npm test in source/ for six conversation-state tests.

## Live backend
The login screen supports a configurable REST API and WebSocket endpoint. External service access and VPN requirements depend on your server and are not verified. HTTPS sites need HTTPS/WSS endpoints. This educational demo is not production authentication.
