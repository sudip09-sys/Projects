# Memory Match

Built by **Sudip Sah** (@sudip09-sys), for Sudip Lab.

Solo and two-player matching, configurable card counts, hints, turn tracking and scoring.

## Run
Serve the repository root with an HTTP server, or open this app through the Sudip Lab workspace. The compiled JavaScript is in build/; no installation is needed to run it.

## Edit
TypeScript source is in src/main.ts. Run npm install and npm run build in this folder after editing.
